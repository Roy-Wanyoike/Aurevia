# Aurevia — Marketing Assets

## Folder Structure
- `videos/` — Product demo videos, walkthroughs, feature highlights
- `images/` — Screenshots, hero images, OG images, presentation slides
- `social/` — Social media assets (Twitter/X cards, LinkedIn banners, etc.)

## Asset Naming Convention
- `aurevia-{view-name}-{description}.{ext}` — e.g. `aurevia-dashboard-overview.png`
- `aurevia-demo-{feature}.{ext}` — e.g. `aurevia-demo-blog-editor.mp4`

## Production Notes
- Videos should be < 50MB for web playback (H.264, 1080p)
- Images should be WebP or AVIF for production, PNG for source
- OG image: 1200x630px
- Twitter card: 1200x600px
- Hero image: 1920x1080px
